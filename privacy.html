Privacy Policy · 2026-11-18

어떤 앱인가요

레나는 한 사람이 자기 폰에서 쓰는 개인 비서 웹앱입니다. 회원 가입이 없고, 일정·할 일·메모 같은 내용은 그 사람의 폰(브라우저 저장소)에만 저장됩니다.

유튜브 연결 (Google 계정)

  • 사용자가 직접 연결을 켜면, 구독한 채널의 새 영상 목록을 보여 주려고 YouTube 읽기 전용 권한(youtube.readonly)만 요청합니다.
  • 구독 목록과 영상 정보는 사용자의 폰에서만 쓰이고, 다른 곳에 저장하거나 남에게 주지 않습니다.
  • 로그인 열쇠(refresh token)는 사용자가 직접 만든 자기 서버(Cloudflare Worker)에만 보관되고, 연결 끊기를 누르면 지워집니다.
  • 영상을 올리거나 지우거나, 댓글·구독을 바꾸는 일은 하지 않습니다.

나누는 정보

광고, 판매, 분석 목적으로 어떤 정보도 다른 사람이나 회사에 주지 않습니다. Google API에서 받은 정보는 Google API Services User Data Policy(Limited Use 포함)를 따릅니다.

지우기

앱 설정에서 유튜브 연결 끊기를 누르거나, Google 계정의 앱 권한에서 레나를 지우면 바로 끊깁니다. 앱을 지우면 폰에 저장된 내용도 함께 지워집니다.

English summary

Lena is a personal, single-user assistant web app. Data stays on the user's device. If the user connects YouTube, the app requests read-only access (youtube.readonly) solely to list new videos from the user's subscriptions on their own device. The refresh token is stored only on the user's own Cloudflare Worker and is deleted on disconnect. No data is sold, shared, or used for ads. Use of Google user data complies with the Google API Services User Data Policy, including the Limited Use requirements.
