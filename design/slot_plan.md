# 해골 빚 슬롯 v2 — 기획서 (승인 전, 코드 0줄)

장르: 슬롯 로그라이크(빚 갚기 + 부적 빌드). 레나 세계관의 **자체 게임**(이름·그림·문구는 앱 것만 씀).
한 판 15~40분, 끝없는 모드로 계속. 영구 강화 없음(v30 원칙) — 대신 **도감·도전 과제·새 부적이 풀리는 것(능력치가 아니라 선택지만 늘어남)**과 **오늘의 판(같은 시드)**으로 계속 하게.

### 부적 36종(시작 풀 24 + 해금 12), 장착 6칸
- 종류: 그림 강화(값+·확률+), 줄 강화(배수×), 판 조작(해골 막기·한 칸 고정), 경제(이자·할인·리롤), 연쇄(조건 달성 시 영구 +1 누적), 저주(강하지만 손해 같이).
- 등급: 흔함/귀함/전설(가게에서 6:3:1).
- 예) "왕관 귀걸이: 왕관 확률 ×2" · "젖은 영수증: 꽝일 때마다 칩 +3" · "해골 우산: 해골 3개 꽝을 한 번 막음(밤마다)" · "레나의 립스틱: 입술 줄이 나오면 그 밤 동안 입술 값 +1 누적" · "할부 계약서(저주): 빚 −30%, 대신 돌리기 −2".

### 레나의 전화(밤마다 1번) — 3개 중 1개 고르기
- 즉시 보상(칩 +20), 이번 밤 효과(행운 +3), 부적 업그레이드, 저주 하나 지우기, 쪽지(일회용 아이템) 받기.

### 쪽지(일회용) 8종, 3칸
- "한 줄 다시 돌리기", "해골 지우개", "같은 그림 칠하기(한 칸)", "이자 두 배" 등.

## ② 경제
- 칩(판 안에서만 쓰는 돈). 시작 칩 10.
- **마감일**: 3밤마다 빚 갚기. 빚 = 30 × 1.55^(마감−1) (마감 1: 30, 2: 47, 3: 72, 4: 112, 5: 173 …).
- **밤 시작 고르기**: "많이 돌리기 7번" 또는 "적게 3번 + 공짜 쪽지 1장" (위험·보상 선택).
- 남은 칩 이자: 마감일에 저금 칩의 10%(부적으로 늘림, 최대 30).
- 가게(밤 사이): 부적 4칸 + 쪽지 2칸, 다시 뽑기 2칩(올라감), 팔기 = 산 값의 절반.
- 게임 동전(오락실): 입장 3, 결과 보상 = 깬 마감일 × 2 (+ 오늘의 판 보너스).

## ③ 난이도(적 대신 '빚'이 압박)
- 마감 5까지 = 1판 클리어(엔딩 연출). 이후 **끝없는 밤**: 빚 배수 1.65, 해골 확률 +1%/마감.
- 빚쟁이 등급 1~8(클리어하면 다음 등급 열림): 시작 칩 −, 가게 값 +, 해골 +, 저주 부적 섞임.
- 오늘의 판: 날짜 시드(같은 날은 같은 판·같은 가게), 하루 기록 저장.

## ④ 조작 (폰 세로, 한 손)
- 레버를 아래로 끌기 또는 큰 "돌리기" 버튼. 돌리는 중 화면 누르면 빨리 멈춤(스킵).
- 부적·쪽지: 누르면 설명, 길게 누르면 팔기/사용.
- 진동은 iOS에서 안 되므로 소리·화면 흔들림으로.

## ⑤ 화면
- 위: 마감일 D-밤(●●○), 빚 / 칩 / 이자 미리보기, 등급.
- 가운데: 기존 슬롯 기계 그림(slot_cab) 안 5×3 릴. 릴은 칸마다 차례로 멈춤, 마지막 칸 앞에서 두 줄이 걸리면 느리게(두근두근).
- 당첨: 줄 그리기 → 그림 튕김 → 숫자가 올라가며 합산("×4 가로 5칸!"), 큰 당첨은 동전 분수·화면 흔들림·레나/해골 한마디.
- 아래: 부적 6칸(발동하면 반짝), 쪽지 3칸, 레버.
- 사이 화면: 레나의 전화(전화기 울림 → 말풍선 3장 카드), 가게, 마감일 결산(빚 갚기 애니메이션), 게임 오버/엔딩, 도감·도전 과제.

## 성능 상한
- 60fps(아이폰), 최악 장면 = 잭팟 연출 + 파티클 150개 + 릴 5줄 회전 동시.
- DOM 요소 ≤ 400, 릴은 transform만(레이아웃 다시 계산 없이), 파티클은 캔버스 1장(150개 상한, 넘으면 오래된 것부터 지움).
- 소리는 WebAudio 합성(파일 0개), 동시 소리 8개 상한.
- 그림은 이미 있는 것만(새 그림 0장, 크레딧 0).

## 기술
- 새 파일 `g_slot.js`(지금 arcade.js 안 슬롯을 옮겨 분리). 계산 코어(돌리기·줄 판정·부적 효과·경제)는 순수 함수 → Node로 수천 판 시뮬레이션 테스트.
- 저장 `S.slot2`(진행 중 판), `S.slotMeta`(도감·도전 과제·해금·등급·오늘의 판 기록). 예전 `S.slotRun`은 끝내고 지움.

- [ ] 레나의 전화가 밤마다 1번 오고, 고른 보상이 바로 적용된다
- [ ] 가게: 사기·다시 뽑기(값 오름)·팔기, 6칸이 차면 못 삼
- [ ] 부적 36종이 각각 설명대로 작동(부적마다 자동 테스트 1개)
- [ ] 쪽지 8종이 각각 작동
