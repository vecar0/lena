# 해골 빚 슬롯 v2 — 기획서 (승인 전, 코드 0줄)

장르: 슬롯 로그라이크(빚 갚기 + 부적 빌드). 레나 세계관의 **자체 게임**(이름·그림·문구는 앱 것만 씀).
한 판 15~40분, 끝없는 모드로 계속. 영구 강화 없음(v30 원칙) — 대신 **도감·도전 과제·새 부적이 풀리는 것(능력치가 아니라 선택지만 늘어남)**과 **오늘의 판(같은 시드)**으로 계속 하게.

## 클로버핏 형식·밸런스 따오기 (v2 수정, 출처: CloverPit 위키 Symbols Board·ATM, Steam "CloverPit Mechanics Explained")
- 이름·그림·이야기·분위기는 가져오지 않음. **판 구조와 숫자 감각만** 따옴. 출처에 없는 숫자(줄 배수·부적 칸 수·시작 칩)는 내가 정한 값이라고 표시.

## ① 오브젝트

### 그림 7종 + 해골 — 5×3 판 (값·확률은 클로버핏 기본값과 같은 곡선)
| 그림 | 값 | 기본 확률 |
|---|---|---|
| 체리 | 2 | 19.4% |
| 동전 | 2 | 19.4% |
| 하트 | 3 | 14.9% |
| 입술 | 3 | 14.9% |
| 번개 | 5 | 11.9% |
| 별 | 5 | 11.9% |
| 왕관 | 7 | 7.5% |
- 부적으로 그림 하나 "+1"이면 그 그림 가중치 +0.8(위 확률은 가중치 1.3/1.3/1.0/1.0/0.8/0.8/0.5에서 나옴).
- **해골 셋(666 자리)**: 확률 화면에 늘 표시, 기본 1.5%(최대 30%). 나오면 **이번 라운드에 들고 있던 칩을 잃음**(ATM에 넣은 건 안전) → "언제 넣을까" 고민이 생김. 행운으로는 안 막힘.

### 줄(패턴) — 보상 = 그림 값 × 그림 배수 × 줄 값 × 줄 배수 (공식은 출처, 줄 값은 내가 정함)
| 줄 | 값 | | 줄 | 값 |
|---|---|---|---|---|
| 가로 3 | 1 | | 대각선 3 | 1 |
| 가로 4 | 2 | | 지그·재그(V/∧ 5칸) | 4 |
| 가로 5 | 3 | | 위·아래(눈썹 모양) | 7 |
| 세로 3 | 1 | | 눈(가운데 둘러싸기) | 8 |
| 잭팟(15칸 한 그림) | 10 | | 겹치는 줄은 모두 따로 셈 | |

### 행운
- 행운 1 = 그 돌리기에서 칸 하나를 '고른 그림'으로 바꿈(고른 그림은 보통 확률로 뽑음). 행운 10이면 거의 꼭 당첨, 15면 잭팟.
- 기본 행운: 첫 마감은 가끔 +4~8, 이후 7의 배수 돌리기 +7~9 / 3의 배수 +5~7 / 나머지 +3~5(가끔), 4번 연속 꽝이면 +5(꽝마다 +1 더).

### 부적 40종(시작 28 + 해금 12) — 전화카드로 삼, 장착 7칸(칸 수는 내가 정함)
- 등급 4단계(흔함·조금 귀함·귀함·전설), 값 전화카드 1~7장. "칸 안 차지" 부적, 충전식(빨간 버튼) 부적, 연쇄(조건마다 영구 누적), 저주(강하지만 해골 확률 등 손해) 포함.

### 레나의 전화 — 마감일마다 1번, 4개 중 1개
- 칩·전화카드·행운·잭팟 값 ×2·부적 칸 +1·가게 할인 같은 보상. 다시 걸기 = (마감 −1)장, 할 때마다 +1. 해골이 나왔던 판 뒤엔 위험한(빨간) 선택지가 섞임.

## ② 경제 (두 가지 돈)
- **칩**: 돌리기로 벎, 빚 갚는 데 씀. **전화카드**: 부적 사는 데 씀.
- 마감일 = 3라운드. 라운드마다 고르기: **돌리기 7번** 또는 **3번 + 전화카드 1장 더**. 레버 값(라운드마다 칩): 7·14·28·42·56·140·168·196·224.
- 칩이 레버 값보다 모자라면 그 라운드는 공짜(전화카드 1장, 7번 쪽으로).
- **ATM**: 칩을 넣어 둠. 라운드 끝마다 넣은 칩의 **7% 이자**. 마감 때 (들고 있는 칩 + ATM)이 빚 이상이면 통과.
- 마감 보너스: 칩 **6 × 마감 번호**, 빚을 일찍 다 갚아 **건너뛴 라운드 하나마다 전화카드 4장**.
- 빚(마감 1~9): 75 · 200 · 650 · 2,200 · 12,500 · 33,000 · 66,000 · 200,000 · 1,000,000 (클로버핏과 같은 곡선, 숫자는 조금 다르게). 10 이후는 끝없는 밤(빚 ×6·×24·…처럼 가파르게).
- 가게 다시 채우기(칩): 3·6·20·69·300·1,000·2,000·7,000·43,000, 그 마감 안에서 할 때마다 1/5씩 오름.
- 시작: 칩 20, 전화카드 2(내가 정함).

## ③ 난이도
- 마감 9(1,000,000) 통과 = 엔딩, 이어서 끝없는 밤.
- 빚쟁이 등급(어려운 모드): 등급마다 빚이 마감마다 누적 +25%.
- 오늘의 판: 날짜 시드.

## ④ 조작 (폰 세로, 한 손)
- 레버를 아래로 끌기 또는 큰 "돌리기" 버튼. 돌리는 중 화면 누르면 빨리 멈춤(스킵).
- 부적·쪽지: 누르면 설명, 길게 누르면 팔기/사용.
- 진동은 iOS에서 안 되므로 소리·화면 흔들림으로.

## ⑤ 화면
- 위: 마감일 D-밤(●●○), 빚 / 칩 / 이자 미리보기, 등급.
- 가운데: 기존 슬롯 기계 그림(slot_cab) 안 5×3 릴. 릴은 칸마다 차례로 멈춤, 마지막 칸 앞에서 두 줄이 걸리면 느리게(두근두근).
- 당첨: 줄 그리기 → 그림 튕김 → 숫자가 올라가며 합산("×4 가로 5칸!"), 큰 당첨은 동전 분수·화면 흔들림·레나/해골 한마디.
- 아래: 부적 6칸(발동하면 반짝), 쪽지 3칸, 레버.
- 사이 화면: 레나의 전화(전화기 울림 → 말풍선 3장 카드), 가게, 마감일 결산(빚 갚기 애니메이션), 게임 오버/엔딩, 도감·도전 과제.

## 성능 상한
- 60fps(아이폰), 최악 장면 = 잭팟 연출 + 파티클 150개 + 릴 5줄 회전 동시.
- DOM 요소 ≤ 400, 릴은 transform만(레이아웃 다시 계산 없이), 파티클은 캔버스 1장(150개 상한, 넘으면 오래된 것부터 지움).
- 소리는 WebAudio 합성(파일 0개), 동시 소리 8개 상한.
- 그림은 이미 있는 것만(새 그림 0장, 크레딧 0).

## 기술
- 새 파일 `g_slot.js`(지금 arcade.js 안 슬롯을 옮겨 분리). 계산 코어(돌리기·줄 판정·부적 효과·경제)는 순수 함수 → Node로 수천 판 시뮬레이션 테스트.
- 저장 `S.slot2`(진행 중 판), `S.slotMeta`(도감·도전 과제·해금·등급·오늘의 판 기록). 예전 `S.slotRun`은 끝내고 지움.
