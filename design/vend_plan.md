# 레나의 자판기 사업 — 기획서 (승인 전, 코드 0줄)

해골 전화국(오락실)과 지금 자판기(선물·꾸미기 가게)를 없애고 하나로 합친다. 9번 자판기 = 이 사업 화면.
비 오는 밤거리 곳곳에 자판기를 세우고 키우는 **계속 키우는 경영 게임**. 앱을 꺼도 장사가 된다(오프라인 수익).
난이도는 쉽지 않게: 재고·가격·고정비·고장·경쟁을 신경 안 쓰면 망한다.

## ① 오브젝트

### 사건(하루 몇 번, 앱 알림으로도)
- 날씨(실제 날씨, 0번 설정의 날씨 켜기): 비 → 우산 ×6·커피 ×1.3, 더위 → 차가운 것 ×1.5, 영하 → 핫팩 ×4.
- 고장, 도둑(현금 일부), 경쟁 자판기 등장(그 자리 14일간 −30%), 시험 기간(4번 공부의 시험 3주 전부터 학원 앞 ×1.5), 축제(대학가 ×3, 하루).
- 가끔 레나 부탁: "오늘 밤 커피 10잔 부스 앞에 채워 둬요" → 해내면 회선 점수.

## ② 경제 (돈 두 가지)
- **게임 동전**(매일 +10, 오락실과 같은 동전): 자리 열기·기계 사기·큰 업그레이드 = '투자'.
- **사업 자금(원)**: 장사로 벌고, 도매·자릿세·일당·수리에 씀. 시작 30,000원.
- 하루 결산(자정): 매출 − 도매 − 자릿세 − 일당 − 버린 것 = 이익. 레나가 아침에 "어제 장사" 한 줄 보고.
- **이익을 게임 동전으로**: 하루 이익 10,000원마다 게임 동전 +1(하루 최대 +10) → 오락실 다른 게임에도 쓸 수 있음.
- **적자**: 사업 자금이 0 밑으로 가면 해골 사채(하루 이자 5%, 한도 100,000원). 한도를 넘으면 가장 비싼 기계를 압류당함.
- **회선 등급(레나 선물)**: 내 상품을 레나에게 '납품'하면(재고에서 빠짐) 회선 점수. 비싼 상품일수록 많이, 오늘의 주파수 상품은 2배(지금 규칙 그대로).
- **부스 꾸미기**: 사업 자금으로 스티커를 삼(지금 스티커 26종 그대로, 값 30,000~200,000원). 지금 가진 스티커·붙인 자리는 그대로.
- 오프라인 수익: 앱을 닫아 둔 동안도 계산, 최대 12시간. 채우기 해골이 없으면 재고가 떨어진 칸은 0.

## ③ 어려움(쉽지 않게)
- 첫 주는 자릿세·도매가에 비해 손님이 적어 **재고·값을 잘 정해야** 흑자. 아무 생각 없이 비싸게 채우면 유통기한으로 버리고 적자.
- 두 번째 자리부터 자릿세가 커서 너무 빨리 넓히면 사채.
- 목표(사업 등급) 8단계: 골목 노점 → … → 밤거리의 자판기왕. 등급마다 조건(하루 이익·자리 수·회선 등급)이 있고 새 상품·사건이 풀림.
- 밸런스 목표(시뮬레이션): '아무 생각 없이 하는 봇'은 7일 안에 사채, '잘하는 봇'은 7일 흑자·30일에 자리 4곳.

## ④ 조작 (폰 세로, 한 손)
- 자리 카드 눌러 들어가기 → 기계 → 칸 누르면 상품 고르기·채울 양·값(−/+ 100원).
- '전부 채우기'(지난번처럼) 버튼, 길게 누르면 상품 설명.
- 결산·사건은 쪽지처럼 위에서 내려옴.

## ⑤ 화면
- 위: 사업 자금 · 게임 동전 · 오늘 이익(실시간) · 사업 등급 막대.
- 탭: **거리**(자리 카드: 오늘 매출·재고 경고·고장 표시) / **창고·도매**(상품 사기) / **알바·업그레이드** / **레나**(회선 등급·납품·부스 꾸미기·오늘의 주파수) / **장부**(7일 그래프·사건 기록).
- 기계 화면: 칸마다 상품 그림·남은 개수·값·유통기한, 팔릴 때 '딸깍' 동전 떨어지는 연출.
- 그림은 이미 있는 것만(부스 b_*, 선물 g_*, 우산 c_umb, 동전 cur/*). 새 그림 0장. (원하면 나중에 크레딧으로 상품 그림 추가)

## 성능 상한
- 시뮬레이션은 '분 단위 계산'을 몰아서(12시간 = 720번, 1ms 안), 화면은 1초마다 숫자만 갱신. DOM ≤ 500.
- 저장 크기 ≤ 60KB(장부는 30일치만).

## 기술
- 새 파일 `vend.js`(계산 코어는 순수 함수 → Node로 30일·수백 판 시뮬레이션), 저장 `S.biz`.
- 없앰: arcade.js의 해골 전화국(`g_idle.js`·`S.idr`), shop.js의 자판기 가게 화면. 옮김: 회선 등급(`S.aff`)·부스 꾸미기(`S.decor`)·선물 데이터.
- 서버 알림: 고장·재고 바닥·결산을 `plan()` 알림으로.
